# Portfolio

## 概要

Web制作・フロントエンド職への転職活動を目的として制作したポートフォリオサイトです。

HTML / CSS / JavaScriptを中心に、これまでの実務経験、スキル、制作実績、Web制作で意識していることを1ページにまとめています。

特に、見やすさ・使いやすさ・レスポンシブ対応を意識し、PC・タブレット・スマートフォンで確認しやすい構成を目指しました。

## 掲載作品

### BlueWorks Studio

架空のWeb制作会社を想定して制作した、HTML / CSS / JavaScriptによる1ページ構成のWebサイトです。

Portfolio内のWorksでは、BlueWorks Studioをiframeで直接確認・操作できるようにしています。

## 工夫した点

- 初めて見る方にも内容が伝わるよう、情報の順序や余白、視認性を意識して構成しました。
- HTML構造やクラスを整理し、後から見返したときにも修正しやすい実装を意識しました。
- Portfolio本体はオレンジ系をアクセントカラーとし、BlueWorks Studioの青系デザインと区別しやすくしました。
- Worksでは静止画だけでなく、実際の制作サイトをその場で確認できるようiframeを使用しました。
- スマートフォンではナビゲーションをハンバーガーメニューに切り替え、Worksのボタンも縦並びにしています。
- 分からない内容は調べ、コードの意味や動作を確認しながら実装・調整しています。

## 実務経験について

Web案件に約7カ月参画し、そのうち約3カ月、HTML / CSS / JavaScript / Vue.jsを使用した画面開発および単体テストを経験しました。

本ポートフォリオでは、その経験を活かしながら、Web制作・UI実装のスキルをさらに広げることを目的としています。
